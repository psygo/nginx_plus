## Learning the costs instead of being told (`learned_cost`)

`least_work_w` above is told each request's expected cost (by the application) and each server's capacity (by the operator). `learned_cost` is told neither: it learns a cost per route and a speed per server from the response times of requests that found their server idle (see `LearnedCost`). The route is the request's class; with 10 % misclassified, the learned table itself is built from the wrong routes for those requests.
